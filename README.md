# 📖 Flipbook de Mini Historias – Cuentos animados con IA

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

Escribe una historia corta y se convierte en un **cuaderno animado**: cada página se dibuja con IA manteniendo el mismo personaje y el mismo estilo, y al final lo exportas como **Short vertical en MP4** con subtítulos, voz narrada y música de fondo. Perfecto para TikTok, YouTube Shorts e Instagram Reels.

👉 **Pruébalo aquí:** [belumoka.com/flipbook-generator](https://belumoka.com/flipbook-generator/)

## ✨ Cómo funciona

| Paso | Qué pasa |
|---|---|
| ✍️ Escribes una idea | Por ejemplo: *"Un zorro pequeño encuentra una linterna en el bosque…"* |
| 🧠 La IA crea el cuento | Lo divide en páginas con principio, nudo y final (con clave de Pollinations) |
| 🎨 Se dibuja cada página | Misma semilla y mismo personaje en todas para que la historia sea coherente |
| ▶️ Lo reproduces | Vista previa como un flipbook, página a página o en bucle de ida y vuelta |
| 🔁 Rehaces lo que no te guste | Seleccionas una página, cambias su descripción y pulsas **Rehacer página** |
| 🎬 Descargas el Short | MP4 con efecto de movimiento, subtítulos, voz y música |

## 📋 Requisitos

- Un navegador reciente: **Chrome, Edge o Safari** (para exportar el MP4 con audio)
- Conexión a internet
- *(Opcional)* Una **clave de Pollinations** (`sk_...`) para que la IA escriba el cuento, narre la voz y cree la música

## 🚀 Uso

1. Abre `index.html` en el navegador (o la página en línea).
2. Escribe tu historia o deja el ejemplo del zorro.
3. Elige **páginas**, **formato** (9:16 para Shorts) y **estilo**.
4. Pulsa **Crear flipbook** y espera a que se dibujen las páginas.
5. Pulsa **Reproducir** para verlo.
6. Pulsa **Descargar Short MP4** para bajar el vídeo.

## ⚙️ Ajustes

| Opción | Qué hace |
|---|---|
| Cómo crear el texto | La IA escribe un cuento nuevo o usa tu texto tal cual |
| Palabras por página | Largo de cada subtítulo (5–30 palabras) |
| Páginas | De 4 a 24 |
| Formato | Short vertical 9:16, cuadrado o horizontal 16:9 |
| Modelo de imagen / texto / voz / música | Ordenados de más barato a más caro |
| Idioma de la narración | Español, inglés, francés, portugués y muchos más |
| Movimiento y subtítulos | Zoom suave entre páginas y texto grande en el vídeo |
| Segundos por página | Duración mínima de cada página en el vídeo |

## 🛠️ Problemas frecuentes

| Problema | Solución |
|---|---|
| Una página sale en rojo o "falló" | Selecciónala y pulsa **Rehacer página**, o cambia de modelo de imagen |
| "Sin clave no puedo escribir un cuento nuevo" | Sin clave se reparte tu texto tal cual. Añade tu clave de Pollinations para que la IA lo escriba |
| El vídeo se descarga sin audio | Usa Chrome, Edge o Safari actualizados |
| Va muy lento | Algunos modelos tienen límite de peticiones por minuto: elige uno más rápido |
| La voz no suena | Pulsa **Probar voz**, cambia de voz o deja "Automática" |

## 🔒 Privacidad

La clave de Pollinations **solo se guarda en tu navegador** (localStorage). Nunca se sube al repositorio ni a ningún servidor propio.

## 💡 Consejo para tus Shorts

Las historias cortas con un personaje claro (un animal, un objeto mágico, un giro final) son las que mejor quedan. Usa **12 páginas en 9:16** con narración activada: sale un Short de unos 30 segundos, ideal para redes.
